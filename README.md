# Axisarium Integration

Local code and tooling workspace for the Axisarium Obsidian vault.

`Axisarium Integration` is the canonical local project workspace. `Aletheion` remains the name of the Daily Sky generator.

## What Lives Here

- `aletheion.py` generates Daily Sky notes from configured natal data and Swiss Ephemeris output.
- `config/aletheion.config.json` points at the live Axisarium vault and stores Aletheion settings.
- `swiss-eph/` contains the local `swetest64.exe` bridge and ephemeris files used by Aletheion.
- `memory/observations.jsonl` stores deterministic Observation-layer records generated by Aletheion.
- `tools/vault_audit.py` scans a vault and writes markdown audit reports.
- `docs/` contains workspace notes, including the repo/vault boundary and the original Aletheion guide.

The live vault is not mirrored here. It remains at:

```text
H:\My Drive\Axisarium
```

## Daily Sky

Generate today's production note into the configured live vault:

```powershell
& "C:\Users\david\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe" .\aletheion.py daily
```

Generate a safe test note into repo scratch space:

```powershell
& "C:\Users\david\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe" .\aletheion.py daily --output ".\scratch\Daily Sky test.md"
```

The configured production output folder is:

```text
H:\My Drive\Axisarium\02 Daily Sky
```

## Observation Ledger

Generate Observation-layer records without rewriting vault notes:

```powershell
& "C:\Users\david\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe" .\aletheion.py observations --discover-vault
```

Observation records are deterministic JSONL entries with `schema_version: aletheion.observation.v1`. They describe calculated sky facts, contacts, exactitudes, house positions, and temporal alerts before interpretation or Mnemosynthesizer review.

## Vault Audit

Run a read-only scan of the live Axisarium vault and write reports into repo scratch space:

```powershell
& "C:\Users\david\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe" .\tools\vault_audit.py --vault "H:\My Drive\Axisarium" --reports-dir ".\scratch\audit-reports"
```

To intentionally update the live vault's `reports/` folder, omit `--reports-dir`.
