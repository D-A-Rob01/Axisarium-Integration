# Aletheion Four-Stage Epistemology

Aletheion should stop collecting symbols and begin curating invariants.

The system separates symbolic material by evidentiary maturity. Each layer moves more slowly than the layer before it and requires stronger evidence before anything is allowed to settle there.

## 1. Observation

**Claim form:** "A thing happened."

Observation is pure contact description. It records event, image, phrase, transit, dream, mood, conversation, or coincidence without assigning symbolic meaning.

This is the astronomy layer:

- what appeared
- when it appeared
- where it appeared
- who or what was involved
- the minimum viable context needed to identify it later

Observation does not infer, diagnose, narrativize, or promote.

Implementation foundation:

- Observation records live in `memory/observations.jsonl`.
- Every record carries `schema_version: aletheion.observation.v1`.
- Observation records may describe sky bodies, moon phase, natal contacts, exactitudes, sign-level matches, natal house positions, and temporal alerts.
- Observation records must not contain Mnemo markers, promotion fields, AURELIUS vectors, or Interpretive Weather language.

## 2. Interpretation

**Claim form:** "This configuration plausibly suggests..."

Interpretation is the Daily Sky layer. It is useful, poetic, and provisional. It belongs to the day or short-lived period in which the configuration is active.

Interpretation is allowed to:

- notice resonance
- offer symbolic hypotheses
- name temporary weather
- connect current experience to known motifs

Interpretation expires. It should not become ontology simply because it was vivid.

## 3. Candidate Memory

**Claim form:** "This motif has repeated."

Candidate Memory is the Mnemosynthesizer layer. It detects recurrence without yet granting trust.

Mnemo is climate rather than weather. It watches for patterns across Daily Sky entries, writings, actions, decisions, conversations, projects, and remembered states.

A Candidate Memory should preserve:

- the repeated motif
- supporting observations
- prior interpretations that invoked it
- open questions
- possible counterexamples
- evidence still needed before promotion

Candidate Memory is not binary. It is a waiting room for corroboration.

## 4. Promoted Pattern

**Claim form:** "This is now part of David's observed symbolic ecology."

A Promoted Pattern is no longer today's astrology. It belongs in its own note as part of Aletheion's ontology.

Examples:

- Grief Witness Protocol
- Sovereign Pressure
- Translation before Explanation
- Teaching as Alchemy
- Care Debt
- Rituals of Recovery
- Public Language Under Pressure

Promoted Patterns should be handled as durable knowledge objects. They may inform future Daily Sky readings, Mnemo comparisons, Aurelius outputs, research decisions, and self-interpretation.

## Promotion Dimensions

Promotion should occur along multiple dimensions rather than through a single binary gate.

| Dimension | Question |
| --- | --- |
| Persistence | Has this appeared repeatedly? |
| Integration | Has David actually acted on it? |
| Productivity | Has it produced writing, teaching, code, research, or decisions? |
| Predictive value | Does it successfully anticipate future experiences? |
| Identity | Does it describe an enduring aspect of the person rather than a passing season? |

Not every promoted signal must score highly in every dimension. Some motifs are temporary developmental weather systems. Others become nearly constitutional.

## Layer Boundaries

| Layer | Temporal Character | Function | Evidence Standard |
| --- | --- | --- | --- |
| Daily Sky | Weather | Interpret today's symbolic atmosphere | Low, explicitly ephemeral |
| Mnemo | Climate | Track recurrence across time | Moderate, corroborated recurrence |
| Axisarium | Geology | Hold slow symbolic invariants | High, multi-dimensional evidence |
| Aurelius | Architecture | Build decisions, language, and practice on settled patterns | Highest, pattern must be operationally useful |

Daily Sky can mention a motif.

Mnemo can track a motif.

Axisarium can stabilize a motif.

Aurelius can build with a motif.

## Promotion Rule

A pattern should not be promoted because it is beautiful, emotionally charged, or recently salient.

Promotion requires evidence that the pattern has become structurally useful:

- it has appeared across more than one context
- it has survived time
- it has changed behavior or interpretation
- it has produced artifacts or decisions
- it helps anticipate future experience
- it describes something more durable than the current season

The core question is not "Is this symbol meaningful?"

The better question is:

**Has this become an invariant in David's observed symbolic ecology?**
